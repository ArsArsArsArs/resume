# Резюме — Арсений Галкин

Статический сайт для GitHub Pages: главная-переключатель и две версии резюме (преподаватель / сисадмин).

Стек: HTML, CSS, немного vanilla JS, [Pico.css](https://picocss.com/) v2 (локальная копия в `assets/`). Без сборки и фреймворков.

## Структура

```
index.html              — главная / выбор резюме
teacher/index.html      — «Преподаватель»
sysadmin/index.html     — «Системный администратор / техподдержка»
assets/pico.min.css     — Pico.css v2
assets/site.css         — тема и вёрстка
assets/script.js        — переключение светлой/тёмной темы
.nojekyll               — отключает Jekyll на GitHub Pages
```

## Публикация на GitHub Pages

1. Создайте **публичный** репозиторий на GitHub (аккаунт `ArsArsArsArs`).
2. Залейте содержимое этой папки в ветку `main` (в корень репозитория).
3. Откройте **Settings → Pages**.
4. В **Deploy from a branch** выберите ветку `main` и папку `/ (root)`, сохраните.
5. Подождите около минуты. Сайт будет по адресу:

   `https://ArsArsArsArs.github.io/<имя-репозитория>/`

Локально можно открыть `index.html` через `file://` — все ссылки относительные.


## Тема

Кнопка ☾ / ☀︎ в шапке переключает светлую и тёмную тему (значение хранится в `localStorage`).
